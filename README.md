# BN-89

A dependency-free local platform fighter with shared keyboard, CPU and controller modes. Open dist/index.html in a desktop browser. Menus and controls fit one screen; text uses original bitmap glyphs and SFX use Web Audio.

## Run and share

Open dist/index.html to play directly. To create a single-file offline version and an email-friendly ZIP, run:

    node scripts/build-download.cjs

The builder writes release/BN-89.html and release/BN-89.zip. Extract the ZIP and open BN-89.html; recipients need no installation or internet connection. Pass an output folder as the first argument to choose another location. The build embeds all game code, styles, and any referenced bundled audio assets. The local Music picker remains available.

Run node test.cjs for regression checks.

## Match modes

Choose **Mode** in the title menu. BN is always the first side and 89 is the second. In CPU modes the human always controls BN and the CPU always controls robot 89; reverse CPU modes have been removed, and older saved choices migrate automatically.

| Mode | BN | 89 |
| --- | --- | --- |
| Classic BN-89 / Shared Keys | WASD, B/N | Arrows, numpad 8/9 |
| Keyboard v CPU | Full keyboard | CPU |
| Controller v CPU | First controller | CPU |
| Keyboard v Controller | Full keyboard | First controller |
| Controller v Keyboard | First controller | Full keyboard |
| Controller v Controller | First controller | Second controller |

Full keyboard means either WASD or arrows for movement/jumping, either B or numpad 8 for attack, and either N or numpad 9 for shield. Overlapping aliases remain held until the last key is released. Keyboard inputs do not control the CPU or controller-owned fighter. **Next Mode** in pause applies to the next match; resuming preserves current assignments.

Choose **CPU: Weak / Medium / Strong**. The CPU moves, attacks, shields, shoots and attempts jumps and recovery using the same input rules and cooldowns as human players. Medium uses the previous Weak behaviour, and Strong uses the previous Medium behaviour. Weak is deliberately docile: it thinks every 800 ms, often idles, rarely initiates melee, and seldom shields or shoots. All difficulties share 40 ms recovery decisions, hold full jumps when needed, aim for return ledges or wall resets, and brake before walking off a platform. Recovery skill is independent of combat difficulty, including Weak. Medium thinks every 360 ms and Strong every 180 ms, with the corresponding previous defence and shooting rates. CPU state and controller routing have automated simulation coverage; controller hardware playtesting remains to be done.

## Controllers

Controller modes are skipped unless the browser detects enough pads: one enables mixed/CPU modes, and two enable Controller v Controller. The menu corner reports no, one or two controllers. Connect a controller and press a button if it has not appeared yet.

The implementation follows the browser [standard gamepad mapping](https://www.w3.org/TR/gamepad/#remapping):

| Input | Action |
| --- | --- |
| Left stick or D-pad | Move / aim; Down drops and fast-falls |
| Bottom face button | Attack |
| Left face button | Jump; release early to short-hop |
| Top face button | Shoot; hold to charge; Up + shoot recovers |
| Any shoulder or trigger | Shield |
| Attack + shield | Shoot chord, as on keyboard |
| Start | Pause |
| Stick / D-pad in menu | Navigate or adjust |
| Bottom face in menu | Select |

The right face button also attacks. **Tap Jump** defaults off: Up aims without jumping, and the left face button jumps. Turn it on to let stick/D-pad Up also jump. Stick movement uses an engage/release deadzone to avoid input jitter. Controller assignments use pad indices, so connecting another pad does not steal an existing fighter. Disconnecting an assigned controller pauses and clears controls; reconnect and resume to bind the replacement. Both rendered controls and input routing follow the selected mode.

## Controls

BN: WASD, B attack, N shield. 89: arrows, physical numpad 8 attack, numpad 9 shield (either Num Lock setting). Jump from the ground at 720 units/sec, then use one spare jump in the air at 800 units/sec. Normal gravity is 2400 units/sec squared and the normal fall cap is 900. The full ground arc rises about 105 units, below the first platform 140 units above the floor; reaching it requires the double jump. Tap and release Up for a short hop: releasing during voluntary ascent halves upward velocity and uses 4000 gravity until the apex. Hold Up through ascent (about 300 ms on the ground jump) for full height. Release does not cut recoil, recovery, or pogo bounces. Walking or dropping off a platform also leaves exactly one spare jump; being airborne never grants two jumps. Landing resets the budget. Press Down during a voluntary rising jump to immediately start falling for a short hop; this also works on the double jump. A tap preserves normal falling and holding Down fast-falls. Down cannot cancel hit knockback or recovery launches. Down also drops through one-way platforms, including while charging a shot; the charge timer and held combo are preserved. Solid floor cannot be dropped through. Dropping starts at 180 units/sec downward speed and holding that same Down press does not fast-fall; release and press Down again to fast-fall. Double-tap a horizontal direction within 230 ms to sprint while held. Walking: 335 units/sec; sprinting: 535.

Menus: WASD/arrows navigate, Enter/Space selects, left/right changes settings. Escape pauses/resumes; R restarts during play. Settings persist locally. A lost-focus tab pauses gameplay and music.

## Knockout and victory displays

Each nonfinal knockout shows both fighters and their remaining lives in large text at the top of the screen for two steady seconds, followed by one second of flickering. Gameplay, surviving fighters, held inputs, attacks and clocks continue normally. The defeated fighter remains hidden and cannot act or be hit during its own three-second respawn timer, then returns with fresh 1.8-second respawn protection. Overlapping knockouts keep independent respawn timers; a later knockout does not delay an earlier respawn. A final knockout shows the winning character and final lives for two seconds before the rematch menu appears. Simultaneous final knockouts announce a draw. Inputs cannot skip the final winner announcement. Normal stock-loss score displays do not block gameplay inputs. Character names remain in the HUD and scoreboard, but are removed from above fighter sprites.

## Combat

Lives are adjustable from 1 to 9 with a default of 3. Choose LIVES in the title menu and use left/right (A/D), or Enter to cycle. The chosen value is saved locally. NEXT LIVES in the pause menu applies to the next match/rematch only. Life counters and the HUD use the value captured when the match begins. Going offscreen costs a life. Each damage segment holds 100 damage. Ground weak punches add 5; aerial side punches add 7; strong, dash, up-air and down-air punches add 10; blocked melee and normal pellets add 2. Blocked projectiles add zero. Horizontal knockback adds upward lift at 72% of horizontal launch force, scaling with damage. Knockback uses gentler 1050 gravity and a 540 fall cap after stun, with reduced neutral horizontal drag to preserve the backward arc; active spikes retain their speed during stun. Launch hitstun lasts 1.5 times its base duration while airborne, including melee, pellets, charged shots and bombs. Landing removes the added half while preserving any remaining base stun; pellet stun protection starts after this adjusted stun. Knockback scales with accumulated damage; at five full segments, only an unguarded strong punch gets the decisive finishing launch boost. Dash punches and charged shots retain normal scaled strong-punch knockback.

Every melee start plays a subtle swing sound, including misses; connecting hits retain their separate impact sound. The swing follows the existing SFX toggle and volume settings. Horizontal attacks start on keydown, last at most 100 ms, and end on release. Shields last at most 500 ms and cancel immediately when the button is released. Connecting melee pushes the attacker slightly away from the shield (120 launch force and 80 ms recoil), without damaging them; shielded down-air does not trigger a pogo bounce. Minimum punch intervals: ground weak 180 ms; strong, side-air and down-air 240 ms; up-air 200 ms; dash 420 ms. After the hitbox ends, attack recovery is 80 ms for weak punches, 140 ms for strong/side/down punches and 100 ms for up-air and 320 ms for dash punches. The minimum interval also applies to early releases. Shield cooldown: 400 ms. Actions are exclusive, with a 45 ms gap after an action ends. Input is not delayed or buffered. The 90 ms attack/shield chord atomically replaces the initial action with shooting. A hit already delivered by an immediate melee is retained.

Punch sequence: the first clean hit is a weak punch (5 damage, knockback scale 0.36 versus a pellet's 0.20). Another consecutive melee started within 2 seconds of that hit is strong (10 damage, full knockback), then the sequence resets. Misses, blocked punches, taking a clean hit, shielding, shooting, recovery, and respawning reset the sequence. A grounded sprint attack is a dash punch with strong-punch damage/knockback and a longer cooldown. Aerial attacks have fixed strengths and reset the ground sequence: side air is 7 damage at 0.50 knockback scale; up and down air are 10 damage at full knockback. Melee hitboxes are 34x34 pixels, centered 39 units from the body center; character hurtboxes remain 36x42. Recovery burst hitboxes are also 34x34. Up air has 100 ms of attack recovery and uses 1.5x upward knockback against grounded opponents and 1.9x against airborne opponents, only when its hitbox intersects the bottom of their body while the attacker is below them. Glancing up-air hits retain damage but knock sideways without upward velocity. Aerials do not receive the ground strong-punch finishing boost.

Vertical aerials: hold up/down and press attack in the air. Up must overlap attack and have been held at least 100 ms to select up-air; a quick jump-plus-attack or tap-release-plus-attack selects side-air. Down within 180 ms before attack also selects down-air. Down pressed during an unconnected side-air converts it to down-air, making either input order usable; a hit already delivered is never converted. Up aerials end automatically after 0.7 sec, even while direction and attack stay held. Jumping, shielding and shooting are available after the usual 45 ms action gap; another melee is available after 100 ms recovery. Down aerials commit for 250 ms; after that release either attack or down, or press shield or an available jump, to cancel. Holding both keeps the down aerial active. Down-air and fast-fall are mutually exclusive. Starting down-air clamps existing fast-fall velocity and removes its forced speed floor. Down-air accelerates normally with its own 1020-unit fall cap, close to the normal 900 and well below regular fast-fall at 1700. Holding Down cannot fast-fall until the down-air ends. Landing or an unblocked hit ends the aerial. Down-air horizontal movement is capped at 85 units/sec. Up-air retains 90% of its starting horizontal momentum, then uses gentle neutral drag and gradual steering toward 268 units/sec while a direction is held, preserving forward drift instead of braking toward the old 85-unit limit. Each swing can hit the opponent once. A connecting down air ends the swing and bounces its attacker upward at 700 units/sec without replenishing jumps. The bounce uses gentler 1650 gravity and a 720 fall cap; the held Down input and recent Down buffer are consumed. Release and press Down again to fast-fall or select another down-air. Against a grounded opponent, down-air has the full horizontal and upward launch of a strong punch. Direction comes strictly from the incoming hitbox relative to the recipient body center: right-side contact pushes left, left-side contact pushes right, and an exact center hit falls back to the attacker facing direction. Airborne recipients retain 0.6x horizontal force and doubled downward spike speed. Shielded grounded hits use the same direction rule and normal shield scaling. Spike speed is preserved during hitstun.

Projectiles: press attack+shield within 90 ms, with both keys held. Pellet cooldown: 200 ms. A single unblocked pellet causes 80 ms hitstun. Holding the combo while grounded and stationary, or while freely falling, charges a large shot after 1 sec; it deals 12 damage and 1.2x base strong-punch knockback, above a grounded dash punch. Horizontal input on the ground or releasing ends charging voluntarily. Incoming melee interrupts immediately. While charging, the first two consecutive incoming projectiles deal their usual damage but cause no stun, knockback or charge interruption. A third projectile within the 1.2-second shot-chain window breaks the charge with the normal 750 ms two-shot stun and reduced knockback, followed by the existing three-second projectile stun protection. Only normal pellets count; charged shots immediately interrupt with their normal force and 190 ms stun; starting a fresh charge clears this counter. The three-shot charge break still applies if normal projectile stun protection was already active. In the air, charging halves horizontal momentum once. Downward speed, falling gravity and fall-speed cap use 45% of normal (slightly gentler than the shield's 50%); the charge fall cap is 382.5 units/sec. Drift is preserved rather than stopped. Left/right changes which way the shot faces without steering the falling trajectory. Ground jumps and the remaining air jump preserve charging and its timer; horizontal steering and voluntary fall-speed changes stay locked while charging; landing preserves accumulated charge and allows existing momentum to ease away. Ground movement input after landing cancels charging, just like normal grounded charging; passive drift alone does not. Switching from an air shield into charging preserves half horizontal momentum and adjusts downward motion to the 45% charge scale without repeatedly halving it. Once charging has been held beyond the initial 90 ms chord window, pressing up cannot convert it into a recovery. Only one large shot fires per hold. The initial pellet still fires immediately. Two consecutive unblocked normal pellets within 1.2 sec produce 750 ms hitstun. The second, stunning shot has only 15% of its normal knockback (an 85% reduction), while damage is unchanged. A blocked shot or melee hit resets the streak. After the triggering stun, the recipient gets three seconds of projectile stun protection: normal pellets still deal damage but cause no stun, knockback, or action interruption. Charged shots bypass this protection, always using full charged knockback and normal 190 ms stun, without building the pellet streak or triggering extended stun. Additional shots during the triggering stun cannot extend it. Protected hits do not build a new streak or refresh protection.

Dash dodge: press shield while sprinting on the ground to dodge horizontally at speed 780 (about 109 units during the burst, 22% farther than before). The first 140 ms are invincible and phase through walls, with no cooldown afterward. Attacks, shielding, jumping and steering unlock immediately when the burst ends. Bomb pickup remains available for 220 ms afterward. Releasing shield does not cancel the dodge. It replaces the old dash-dodge melee counter; ordinary shields still absorb projectiles and earn automatic parry.

Recovery: in the air, hold up and press the shoot combo (up can also be the last of the three keys). A dot appears above the character. Aim left/right for up to 500 ms. Release either shoot-combo button (or the controller top-face shoot button) to launch early at the current angle; holding both keeps aiming until the automatic launch. Releasing the aim direction alone does not launch. Entering aim reduces horizontal drift to 65% and downward momentum to 40%; aiming uses 600 falling gravity and a 340 fall-speed cap. Then launch automatically with an 80 ms burst at base speed 690. Straight-up recovery launches at 750, with the 60-unit bonus tapering smoothly toward angled launches. During the burst, a body hitbox deals side-air damage (7) and knockback (0.5x base force), once per launch. The selected Weapon sprite marks the burst hitbox. It overrides enemy side-air, but an enemy up-air or down-air cancels it; priority is the same for either player. Launch contact is melee for projectile-parry cancellation. Recovery flight retains 1500 gravity, separately from the faster jump gravity. Landing during aiming cancels recovery and resets its availability. A recovery can be interrupted by hits, consuming it. Launch locks melee, shields, shots, jumps, air steering and fall-speed changes until landing. Landing or respawning resets recovery availability.

Air dash: double-tap left/right within 230 ms and press shield within 200 ms of the second tap while airborne. Shield may be pressed just before or after the second tap. Launch is immediate, horizontal at speed 640, with a fixed 140 ms burst followed by gravity. It shares recovery lockout: no melee, shield, shots, jump, second dash, recovery, steering or fall-speed change until landing. The 140 ms horizontal burst is invincible to melee and all projectiles. Protection ends exactly when gravity resumes, or sooner on landing. Projectiles pass through during invincibility. Hits during the subsequent freefall do not restore actions. This protection applies to air dash, not the aimed recovery. Ground double-tap plus shield performs a dash dodge.

Pellet reflection: blocking any projectile absorbs it and arms automatic parry. After the shield ends, the player can move, jump and act freely while all incoming normal and charged projectiles reflect at 1.5 times their original speed. Reflection transfers ownership, preserves projectile damage, and causes no damage or recoil to the reflector; repeated reflections do not compound speed. Parry has no timeout and is not consumed by reflection. Any connecting enemy melee attack cancels it, including weak, strong, aerial and shielded hits. Respawning or restarting clears it.

## Sprint-jump aerial boost

Jumping from a sprint opens a 1.1-second boost window. Side-, up- and down-air hits during that window deal 12 damage and use the charged-shot 1.2x base force instead of their normal damage/force. Directional up-air and spike properties still apply. Air jumps do not refresh the window, landing clears it, and a long-held attack loses the boost when the window expires.

## Bombs

The growing pellet sprite flickers during the final 240 ms of charging as a planting cue. Hold Down when a shot charge completes to plant a bomb instead of firing the charged shot. It appears beside the fighter's feet, just outside their body; clear space behind is used if a wall blocks the front. The initial uncharged pellet still fires at the start of charging.

Planted bombs remain fixed with no fuse timer. Contact, an active melee/recovery attack, or a projectile detonates them. Explosions have a 115-unit radius, deal 18 damage, and launch harder than a charged shot (1.9x base force). Both fighters, including the planter, are affected. Bombs can trigger nearby bombs in a chain reaction. Existing spawn and air-dash invincibility still work. Explosions interrupt charging as a heavy attack, rather than counting as ordinary pellet hits.

Shielding an explosion still takes the full 18 damage but adds no knockback or stun; automatic pellet parry does not block a blast. Dash dodges and air dashes pick up unheld bombs within a 12-unit margin around the fighter throughout their 140 ms invincible burst and the following 220 ms pickup grace period instead of detonating it. The carrier can move normally after their shield ends.

- **Attack while carrying:** throw in the held cardinal direction (Up, Down, Left or Right), defaulting to facing forward. Forward throws fly straight for 80 ms before falling with lighter 550 gravity. Throwing during a dash increases forward speed from 650 to 820 and extends straight flight to 140 ms. An airborne downward throw halves drift and falling speed, caps descent at 425 for 650 ms, and consumes held Down so fast-fall needs a fresh press. Jumping, recovery, landing or being launched ends this slow fall. Upward throws pass through one-way platforms and land on top when descending. Downward floor-level throws rest on the platform. Thrown bombs do not trigger on their thrower or damage, stun or launch them, including after sticking to a surface. Picking up a bomb clears its previous thrower; the next throw protects the new thrower.
- **Shield while carrying:** detonate in hand with shield protection, taking damage without added knockback.
- Carried bombs cannot be detonated by contact, attacks, projectiles or nearby explosions. Only the holder pressing Shield detonates one in hand, with the usual shield protection. Once thrown or dropped, normal detonation triggers resume.
- Thrown bombs stick to wall faces/caps and follow moving walls. Landing on a platform also makes them stay there; the same contact/attack/projectile detonation rules apply.
- Bombs persist across stock losses. A carried bomb is released on stock loss, bombs fully outside the arena are discarded, and a new match clears all bombs.

The sidebar includes a Down: Bomb reminder beneath the charging controls. Bombs use a simple solid bitmap silhouette and an expanding blast ring.

## Walls and recovery

Two 180-unit outer walls move vertically in opposite phases on a six-second Pong-style cycle. The center wall extends from beneath the solid platform through the lower knockout boundary, with 100-unit downward lips beneath the two extended grey jump-through sections. Each lip starts at y=600, leaving a clear 62-unit gap (one body height plus 20 units) below the jump-through platform underside at y=538, with room to jump through on either side. Outer walls are 14 units wide, the center wall is 16, and lips are 12; all are plain filled rectangles without inset markings and have collision on both sides and their caps. Projectiles travel through walls.

Airborne side contact limits voluntary downward movement to 180 units/sec. Press Jump to rise at 720 upward speed while facing and hugging the wall. Holding toward the wall stays flush against it; holding away adds a 180-unit horizontal escape kick. The initial 60 ms preserves jump momentum, and one spare air jump remains. Repeated contact allows climbing. Touching a wall cancels any active melee attack, including a committed up-air or down-air, and resets melee/action readiness so jumping and other actions are available immediately; enemy hitstun remains in force. Shot charging survives wall contact. Touching a wall after the recovery or air-dash burst restores actions, the spare jump, and recovery availability without grounding the fighter. Charge progress survives wall contact, platform drops and wall jumps. As with other charged jumps, wait beyond the initial shoot chord before pressing Up if you want a jump rather than aimed recovery.

Attack-launched fighters bounce off wall faces and caps at 80% of their incoming relative speed, with a brief impact stun. Moving-wall rebounds account for wall velocity. Ordinary contact slides or stops rather than bouncing. The invincible 140 ms air-dash burst phases through walls; once it expires, collision returns, and an overlapping fighter is moved safely outside. Spawn invincibility does not bypass wall collision. Landing or regaining voluntary movement clears the attack-launch bounce state.

## Stage

The main platform has a solid 432-unit center and grey 144-unit one-way sections on both ends. The center blocks rising through its underside and lateral entry; it cannot be dropped through. Grey ends and the three upper platforms allow jumping up and dropping down. Landing works on every section. Both sides of each downward lip sit below grey jump-through surface, and the main platform uses a flat fill with no layered shadow. The arena camera is zoomed to 90% to show more outside space in every direction. The view is shifted down by 35 world units for additional room beneath the stage, with the lower knockout boundary aligned to the visible bottom edge and the upper knockout boundary preserved. A thin continuous line marks the exact fall-death boundary; the old perforated guide is removed. HUD, menus and controls retain their size. Side and upper blast boundaries, along with projectile culling, extend beyond the wider visible region.

## Weapon and shield indicators

The menu option **Weapon** cycles through **Fist** and **Sword** using left/right or Enter. Fist restores the original 34x34 square. Sword is a short, thick rectangular blade, a full-height crossguard and a small hilt, drawn as three solid rectangles that rotate with the attack direction. The glove is removed. Upward sword blades are 12 units wide rather than 18, while horizontal and downward blades keep their existing proportions. Upward sword attacks have a two-unit border in the background color to separate them from ears and antennae; the hitbox remains unchanged. The saved choice changes only the sprite; both use the same hitbox, damage and timing. Older saved square/glove choices migrate to Fist, and old Sword choices remain Sword.

Active shielding displays a solid shield silhouette above the fighter in the palette ink color. Joined rectangular tiers eliminate the pixel-grid seams, and a small cross is cut out in the background color. Automatic projectile parry displays the same shield in grey. Active shielding takes visual priority if both protections are present.

## Palettes

Paper, Pocket, Amber, Ice, Berry, Sunset and Hell can be selected in the keyboard menu, with inversion available for every palette. Sunset pairs peach with plum silhouettes; Hell uses hot vermilion with deep red silhouettes. Existing palette selections retain their indices.

## Music

The default looping track is Never Gonna Give You Up (8 Bit Remix Cover Version) [Tribute to Rick Astley] by 8 Bit Universe, supplied by the project owner. It is bundled with the hosted game and embedded in the standalone download. Playback starts after a keyboard interaction.

Select CHOOSE MUSIC on the title or pause screen, press Enter/Space, and choose a browser-supported audio file such as MP3 or WAV. The file loops through a dedicated music gain channel. MUSIC and SFX have separate toggles and 0-100 volume settings, adjusted in steps of 10 using left/right (A/D). Defaults are Music 25 and SFX 80. Both share a compressor; music briefly ducks during effects so they remain audible together. Volumes persist locally. The chosen file is saved with IndexedDB on this device/browser when storage is available; otherwise it lasts for this session. It is not uploaded to the hosted site or shared with other visitors. A keyboard interaction unlocks playback after reloading.

## Validation

Run `.tools/node.exe test.cjs` for combat/menu regression checks. The `.tools` directory is ignored and contains local development runtimes and browser QA artifacts only. Gameplay constants are in dist/game.js. No external font/audio assets or dependencies are needed.
